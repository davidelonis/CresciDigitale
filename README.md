# CresciDigitale

Sito web ufficiale di **CresciDigitale** - Partner per la trasformazione digitale e l'innovazione con l'Intelligenza Artificiale.

## Descrizione

CresciDigitale è una società di consulenza tecnologica specializzata nella trasformazione digitale e nell'implementazione di soluzioni di Intelligenza Artificiale per aziende, scuole e pubblica amministrazione.

## Servizi

- **Intelligenza Artificiale Generativa**: Assistenti AI, chatbot, knowledge management
- **Consulenza Strategica Digitale**: Audit tecnologico, roadmap di trasformazione
- **Sviluppo Software Personalizzato**: Applicazioni web e mobile, soluzioni cloud
- **Formazione Digitale**: Corsi su AI, workshop aziendali, certificazioni
- **Data Analytics & Business Intelligence**: Dashboard, analisi predittiva, reportistica
- **Supporto e Manutenzione**: Help desk 24/7, manutenzione evolutiva

## Tecnologie Utilizzate

- **HTML5**: Struttura semantica moderna
- **CSS3**: Design responsive con CSS Grid e Flexbox
- **JavaScript**: Interattività e animazioni
- **Google Fonts**: Tipografia Inter

## Caratteristiche

- Design moderno e professionale
- Completamente responsive (mobile-first)
- Animazioni fluide e coinvolgenti
- Ottimizzato per le performance
- SEO-friendly
- Accessibilità WCAG

## Come Visualizzare il Sito

1. Clona il repository
2. Apri il file `index.html` nel tuo browser
3. Oppure usa un server locale come Live Server

## Sezioni del Sito

1. **Home/Hero**: Introduzione con statistiche e CTA
2. **Servizi**: Panoramica completa dei servizi offerti
3. **Chi Siamo**: Presentazione dell'azienda e valori
4. **Formazione**: Programmi formativi per aziende, scuole e PA
5. **Contatti**: Form di contatto e informazioni

## Personalizzazione

### Colori

I colori principali sono definiti nel file CSS attraverso variabili CSS:

```css
--primary-color: #667eea;
--secondary-color: #764ba2;
--accent-color: #f093fb;
```

### Contenuti

Per modificare i contenuti, edita direttamente il file `index.html`.
